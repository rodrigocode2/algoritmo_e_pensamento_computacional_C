#  Repositório de Exercícios em C

Este repositório reúne códigos, algoritmos e exercícios práticos desenvolvidos durante meus estudos da linguagem C.

##  Estrutura de Pastas

- `/01-introducao`: Conceitos básicos, sintaxe, entrada/saída.
- `/02-condicionais`: Tomada de decisão (`if`, `else`, `switch`).
- `/03-repeticao`: Estruturas de repetição (`for`, `while`, `do-while`).

## 🛠️ Ferramentas
- **Linguagem:** C (ANSI C)
- **Compilador:** GCC
- **IDE:** VS Code
